# Layela Moyo — Software Engineering Portfolio

A responsive React portfolio website using Vite.

## Run locally

1. Install [Node.js](https://nodejs.org/) (LTS recommended).
2. Extract this project folder.
3. Open a terminal in the project folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Build for deployment

```bash
npm run build
npm run preview
```

The production website is generated in the `dist/` folder.

## Before publishing

Search the project for these placeholders and replace them:

- `your.email@example.com`
- `your-profile`
- `your-username`
- “Add your ...”
- Project evidence notes

Add screenshots for Kimply, Ticket to Ride / UNO, From Shelves to Screens and Is Australia a Big Spender. Update each project description to reflect your exact personal contribution and link to the relevant repositories or live demos.
